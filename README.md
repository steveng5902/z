# 🟪 Assignment 1 - HTML & CSS

## 🎯 Purpose

- Build a front-end web application GUI with HTML and CSS
- Add appropriate HTML elements in accordance with semantic best practices
- Use Tailwind utility classes to add CSS styling
- Use the HTML `<canvas>` element and JavaScript to render a visual grid

## 📦 Project Structure

The starter code contains the following:

- 🛠️ `/index.html`
- 🚫 `/style.css`

**Legend:**

- 🔎 = content should be viewed
- 🛠️ = content requires modification
- 🚫 = content must **not** be edited

## 🧪 Demo
